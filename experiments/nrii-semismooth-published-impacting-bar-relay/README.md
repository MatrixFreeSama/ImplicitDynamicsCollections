# NRII ↔ Semismooth Published Impacting-Bar Relay

## Purpose

This branch tests a relay interpretation of NRII on a published-parameter 1D elastic-bar impact problem. NRII is not required to cross the nonsmooth unilateral-contact event. Instead, a Matrix-Free NRII implicit-midpoint coefficient cascade owns the smooth bulk state and separately constructs the unit-impulse response information consumed by an exact Fischer-Burmeister semismooth contact node.

The two solvers keep incompatible mathematical contracts. NRII remains locally analytic and non-residual-iterative; the semismooth node explicitly accepts the generalized derivative required by the nonsmooth complementarity event. Their interaction is limited to declared state and impulse-response handoff data.

## Model

Published-parameter 1D elastic bar impact benchmark:

- bar length: 0.254 m
- cross-sectional area: 6.45e-4 m^2
- Young's modulus: 211 GPa
- density: 7847 kg/m^3
- launch speed: 5 m/s toward the unilateral wall
- restitution: e = 0
- uniform P1 bar elements
- CFL fraction: 0.7
- locked scaling meshes: Ne = 50, 200, 1000, 5000

Analytical reference scales used by the benchmark are

- wave speed c = sqrt(E/rho)
- bounce time tb = 2L/c
- contact-force scale F0 = rho*c*v0*A

The timed hot path contains no dense matrix assembly, LU factorization, or dense direct solve.

## Locked relay policy

The smooth bulk map is advanced by a fixed-order Matrix-Free NRII implicit-midpoint coefficient cascade with order 64. The original-equation residual is measured only after candidate construction and does not produce a correction direction.

The unit-impulse response handoff data is generated by a second one-way NRII cascade, also at order 64. The contact node receives only the free-contact state and this response information.

Contact is formulated as the exact Fischer-Burmeister nonlinear complementarity problem and solved by semismooth Newton. Strict ordinary Newton at the natural exact-FB corner (p,w) = (0,0) is recorded only as a formulation-domain control. Its undefined ordinary Jacobian is not interpreted as a claim that every Newton-family method fails.

## Main result

The first unconstrained NRII smooth candidate satisfies its own implicit equation while moving the wall-contact node to -3.428801592e-06 m. The candidate is therefore equation-valid but unilateral-domain-invalid, and contact authority transfers to the semismooth node rather than forcing NRII across a nonsmooth event.

## Interpretation

This experiment supports the statement that solver incompatibility does not imply relay incompatibility. NRII and semismooth Newton do not share a correction equation, differentiability assumption, Jacobian contract, or state-update loop, yet they can cooperate through a narrow declared interface.

The mesh sweep also shows the physical observables moving toward the analytical bar scales as the mesh is refined: release time approaches tb and the median contact force approaches F0.

This does not prove a universal performance advantage, and it does not establish a GPU speedup. It is a correctness, domain-separation, and solver-relay architecture experiment.

## Timing note

The current measurements are CPU results from Numba JIT + NumPy arrays. The cloud runtime exposed no CUDA device, so GPU timings are deliberately absent rather than estimated from CPU measurements. A later GPU implementation should preserve the same numerical contract and replace only the execution backend.
